  Les tests vérifient : export refusé sans connexion ; seul le dépotoir vérifié sort ; aucun
  champ de déclarant, ni photo, ni source, ni commentaire ; aucune trace du nom ou du téléphone

  est valide ; l'outil en ligne de commande écrit exactement la même chose que l'API.
- Comment ça marche : on prend les dépotoirs actifs dont au moins un signalement est vérifié
  (même requête que le mode strict du plan). Pour chacun, on publie seulement :
  - son identifiant, sa position et sa date d'observation ;
  - le type de déchets le plus souvent indiqué ;
  - volume, surface, mode de dépôt ;
  - nombre de signalements et de sources, première et dernière observation, étape du dossier.

  Le commentaire libre est exclu, parce qu'un habitant peut y écrire un nom. Une entité sans
  position ou sans date n'est pas publiée.

  ```bash
  python outils/exporter_signalements.py      # lit donnees/ouagadougou/signalements.sqlite
  ```
